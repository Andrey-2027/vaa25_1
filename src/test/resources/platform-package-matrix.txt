# Его рёбра не были видны матрице по построению: забор читает только org.ipro, а адаптеры

# границу артефакта: сначала UI-адаптер, потом подсистема — то есть условие оценивалось бы
# до появления sink'а, и обработка ошибок UI выключалась бы молча.
