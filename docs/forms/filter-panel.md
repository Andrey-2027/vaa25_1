# Панель отборов списка

Панель объявляется в существующем классе конфигурации списка. Подпись принадлежит
`FieldMetadata.label`, вид редактора определяется типом реквизита.

```java
public void configure(ListFormVariants l) {
    l.filterPanel(
        l.filter("journal").setRequired(true),
        l.filter("date").setLabel("Период").setPeriod(),
        l.filter("receivingWorkshop"));
}
```

Пустые поля не ограничивают просмотр. Обязательность запрещает только создание:
в подсказке и доступном описании команды показывается причина «Сначала выберите: Журнал».
Ссылка, enum и boolean задают равенство; строка — поиск по вхождению без учёта
регистра, `%` и `_` трактуются как обычные символы. `.setPeriod()` включает общий
редактор периода для LocalDate / LocalDateTime с включёнными границами.
Смена черновика периода не перезагружает список до «Применить».

Значения равенства по прямому реквизиту подставляются в новую запись, включая
необязательные поля. Текстовый поиск, период, коллекции, вложенные пути и поля
со своим условием не подставляются. Значения панели не сохраняются между открытиями.
Настройки колонок, прежние виды и фильтры в шапке продолжают работать отдельно.

По умолчанию поля вертикальны. Для связанной группы:

```java
l.filterPanel(l.filter("journal").setRequired(true),
    l.horizontal("periodAndWorkshop",
        l.filter("date").setPeriod(), l.filter("receivingWorkshop")));
```

Подписи горизонтальной группы по умолчанию в строку. Перегрузка
`horizontal("periodAndWorkshop", true, ...)` располагает подписи над полями.
При узком контейнере группа становится вертикальной. У ListForm нет переключателя
компактности; старое сохранённое значение compact игнорируется и не меняет поля панели.
Панель всегда находится над списком и не сворачивается. Размещение команд описано
в [руководстве меню списка](list-command-menu.md).

Своё условие задаётся без обработчика интерфейса:

```java
l.filter("name").setCondition(value ->
    (root, query, cb) -> cb.equal(root.get("externalCode"), value));
```

`.setSelectionFilter(Map.of("type", allowedType))` одинаково ограничивает
автокомплит ссылки и её диалог выбора. Диалог выбора по умолчанию получает
декларации новой панели списка; собственные объявления выбора и его вариантов
сохраняют приоритет. `contextFilters()` — совместимый вход с прежним равенством;
дублирование пути в нём и в `filterPanel` даёт предупреждение при старте,
новое объявление имеет приоритет. Некорректный путь нового объявления — ошибка
старта с классом конфигурации и именем поля.

## Ограничение открытия

```java
navigator.openFilteredListForm(PrdSpec.class, null, Filter.eq("journal", journal));
```

`Filter` находится в `org.ipro.form.registry`; путь и тип значения проверяются
перед открытием. Для встраивания есть `createFilteredListForm`, для готового списка —
`form.setOpeningFilter(Filter.eq(...))`. Эти ограничения видны только для чтения
с пояснением «Задан при открытии» и сохраняются при очистке пользовательских отборов.
Карта `contextFilters` и старые seed-параметры остаются входами совместимости.

## Периодические регистры

Стандартное семейство помещает «Представление» и период в ту же верхнюю область:
«История» использует общий PeriodField, «Срез последних» — «На дату».
Исторический диапазон не влияет на выбор победителя среза и не сохраняется.
Фильтр периода в шапке отключается свойством колонки формы в списке и выборе.
Атрибута `FieldMetadata.inlineFilter` больше нет; настройка принадлежит
`ListColumns.Column.inlineFilter` / `FormColumnDeclarations.Properties.setInlineFilter`.

Полный последний день LocalDateTime преобразуется в SQL как `< начало следующего
дня`: это исключает попадание следующей полуночи из-за округления PostgreSQL.
В модели редактора конец дня остаётся LocalTime.MAX.

Обязательный журнал ReceivingDocument учитывается каталогом маршрутов:
прямая ссылка на список без контекста журнала недоступна по существующей политике
маршрутов. Передача такого контекста через URL остаётся задачей RouteContextCodec.
