# Р8: единое дерево, редактируемый срез и представления ссылок

Дата: 2026-10-08. Итерация 4 пилота. Стандартная ListForm с переключением
истории / среза остаётся следующей частью Р8.

## Как попробовать

1. Запустить пилот привычной конфигурацией IDEA либо
   `./scripts/accounting-object-pilot.ps1 -Mode Run`.
2. Открыть редактор запроса отчёта. В обоих окнах дерево имеет группы
   «Справочники», «Документы», «Регистры», «Прочее» и одинаковый поиск.
   В дереве три колонки: наименование, имя в запросе и тип объекта; тип поля
   показывается в подсказке. Табличные части находятся под владельцем. Для регистра доступны
   «Записи регистра» и поддерживаемый «Срез последних».
3. Вставить запрос:

```sql
select s.nomenclature as nomenclature,
       Представление(s.nomenclature) as nomenclatureName,
       Представление(s.recorder) as recorder,
       Представление(s.accountingType) as accountingType
from СрезПоследних(
    NomenclatureAccountingObject,
    :parDate,
    workshop = :parWorkshop
) s
```

4. Нажать «Проверить». В тестовых параметрах указать дату через обычный
   DateTimePicker и выбрать цех для `parWorkshop` через выбор справочника.
   Дата и используемые параметры обязательны. Пустое значение не снимает отбор.
5. Нажать «Конструктор». Выбрать итоговый запрос и таблицу среза.
   «Настроить срез» показывает обе фазы отбора. В строке отбора выбрать
   «Значение» или «Параметр»; можно выбрать существующее имя или ввести новое.
   Несовместимое повторное использование имени отклоняется.
6. Для обычной ссылки или поля среза выбрать «Добавить представление».
   Функцию также можно вписать вручную в SELECT.
7. Применить конструктор, проверить запрос, настроить поля макета и сохранить.
   Повторно открыть отчёт, проверить тот же цех / дату и экспортировать результат.

Вне регистров функция работает так же:

```sql
select n.code as code,
       Представление(n.unitOfMeasurement) as unit
from Nomenclature n
```

Подпись определяется действующими правилами `InstanceNameResolver`; для единицы
измерения это её краткий код, для документа пилота — номер и дата.

## Язык запроса

`СрезПоследних` и `Представление` — расширения языка отчётов приложения.
Перед Hibernate запрос преобразуется в обычный HQL и проходит проверки доступа.
Редактируется краткая запись; полный HQL доступен отдельно по кнопке
«Показать сформированный запрос». «Редактировать текст» переключает полный HQL
в MANUAL. При ошибке краткий текст остаётся для исправления; старый пакет
вместо ошибочного текста не выполняется.

Отбор измерений — необязательный третий аргумент. Дополнительные аргументы:

```sql
from СрезПоследних(
    NomenclatureAccountingObject,
    :parDate,
    workshop = :parWorkshop,
    послеСреза = (accountingType = :parType and period >= :parStart),
    регистраторы = (('accounting-object-installation', 123))
) s
```

Все внутренние условия соединяются **И**. Измерения фильтруются до выбора
победителя; ресурсы и период — после. Внешний WHERE сохраняет обычный смысл.
Отбор «послеСреза» автоматически во внешний WHERE не переносится.
Область «Все регистраторы» в тексте не печатается.
Параметр ссылки хранит сущность, а внутренний параметр среза получает её ID
после проверки доступности. Тот же сущностный параметр можно использовать
в обычном WHERE, например `d.workshop = :parWorkshop`. Тип по произвольному
числовому ID не угадывается.
Поддерживаются несколько срезов, независимые JOIN / LEFT JOIN и обычные CTE.
Произвольные старые CTE не распознаются автоматически как срез.

## Представления и доступ

`Представление(n)`, `Представление(d.journal)`, `Представление(r.recorder)`
и `Представление(s.recorder)` возвращают String. Измерения / ресурсы среза
сохраняют тип целевой ссылки. Для регистратора используются `typeCode` и `id`.
Общий сервис слоя чтения группирует уникальные ссылки по типу и получает их
пакетами до 200 через canonical read либо зарегистрированную read policy.
Форменный сервис регистратора использует те же подписи и сохраняет ссылки
открытия документа.

Пустая ссылка возвращает `null`. Отсутствующий / недоступный документ возвращает
«Документ недоступен», другой объект — «Объект недоступен».
Обычный внешний ключ читается у доступного владельца; подпись целевого объекта
получается отдельным защищённым чтением. Недоступная подпись не удаляет строку.
Обычная проекция полей связанного объекта сохраняет прежние ENTITY / RLS проверки.
ATTR-проверки не добавлены.

Preview, выполнение отчёта и экспорт используют итоговую схему без служебных
колонок идентификаторов. В первой версии функция разрешена самостоятельной
колонкой итогового SELECT. WHERE, JOIN ON, ORDER BY, HAVING, GROUP BY,
вложенные выражения и DISTINCT с представлением отклоняются.

## Сохранение и совместимость

Краткая запись и конструктор работают с одним `VisualQueryPackage`.
После применения сохраняются VISUAL JSON, настройки источников и полный HQL.
Блок «НАСТРОЙКИ СРЕЗА» больше не формируется для новых пакетов.
Старые литеральные настройки читаются, обычный ручной HQL продолжает работать.
Миграция таблиц не требуется. Отмена окна восстанавливает исходный запрос,
режим, JSON и параметры, включая удалённые во время редактирования.

## Классификация источников

Группы определяются разрешёнными метаданными и реестром регистров.
Для существующих справочников цехов, журналов, филиалов, единиц измерения,
групп номенклатуры, типов и значений атрибутов явно указан CATALOG.
Источники без установленного вида остаются в «Прочее»; название сущности
само по себе не используется для угадывания её вида.
