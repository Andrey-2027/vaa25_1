# Обсуждения и исторические материалы

Discussion-документы содержат рассуждения, альтернативы и промежуточные оценки. Они не являются текущим планом реализации и не должны интерпретироваться как инструкции.

Исторические источники текущего roadmap:

- локальный архив `JMIX_GitVaa_Roadmap.md`;
- `JMAX vs GitVaa_Обсуждение.txt`;
- `JMIX_GitVaa_Мнение2.txt`;
- `JMIX_GitVaa_Мнение3.md`.

Исходные файлы обсуждения не копируются автоматически в репозиторий. Принятый результат фиксируется в ADR и актуальном roadmap.

Если discussion расходится с ADR или roadmap, действуют ADR и актуальный roadmap.
