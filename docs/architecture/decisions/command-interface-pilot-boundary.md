# Решение о границах пилота командного интерфейса

Дата: 2026-10-10. Объём: [Пилот 1, КИ-1–КИ-5](../command-interface-pilot-plan.md).

`platform-navigation` владеет устойчивыми ID, декларациями defaults, чистым
resolver видимости и внутренним хранилищем профилей/назначений. Модуль не зависит
от Vaadin, приложения, классов User или каталога маршрутов. Приложение предоставляет
строгий административный policy и адаптер стабильного ID/поиска пользователей.

Профиль регулирует только видимость существующих пунктов. Он не меняет membership
подсистем, права, capabilities, публикацию маршрутов или доступ по прямой ссылке.
SHOW не преодолевает отказ чтения; HIDE предка блокирует потомков. Отсутствие
назначения означает developer defaults с общей фильтрацией и удалением пустых узлов.
Неизвестные сохранённые ключи остаются до явного сброса.

Один UI получает один снимок дерева для меню и плиток. Изменения становятся видны
после обновления/нового входа; ошибка чтения профиля показывается явно. Редактор
принадлежит приложению, каждая серверная административная операция защищена.
Назначение привязано к неизменному ID пользователя, а не логину.

КИ-5 поставляет отдельный opt-in PostgreSQL launcher с явными grants и обычной
canonical-записью. Фикстуры вложенности отсутствуют в стандартном classpath.
Стандартный флаг остаётся выключенным. Служебные/legacy-пункты, порядок,
массовые назначения, live-update, экспорт и миграции ID выходят за этот пакет.

Приёмка означает готовность к пользовательской пробе, а постоянное включение
и переход к единственному построению меню требуют решения по результатам пробы.
Инструкция: [пользовательская проба](../command-interface-user-trial.md).
