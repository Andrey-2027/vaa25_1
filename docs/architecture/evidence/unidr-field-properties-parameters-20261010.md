# UniDR: свойства полей и вкладка параметров — 2026-10-10

В палитре поля добавлены относительная ширина, выравнивание и формат числа/даты. Настройки хранятся в `UniDrDefinition.fieldStyles`; старые JSON без этого свойства читаются с настройками по умолчанию. Ширина задаёт соотношение колонок при подгонке отчёта под страницу. Форматы и ширина проверяются серверным валидатором. Сборщик применяет свойства к колонкам и числовым итогам, включая PDF и XLSX; числа XLSX сохраняют числовой тип.

Объявления параметров вынесены во вкладку «Параметры отчёта». Для стандартного источника доступны подписи, начальные значения и добавление параметров отбора. Для произвольного запроса используется существующий `ReportParamEditor` UDR: вид параметра, класс сущности, обязательность и значения по умолчанию. Изменения параметров запроса применяются отдельной кнопкой; до применения запуск блокируется. Отмена сохраняет применённое объявление. Значения текущего запуска остаются рядом с кнопкой «Сформировать».

Параметры стандартного источника с типом «Сущность» используют `EntityField` и штатную форму `SelectionFormAssembler`, как в UDR. Выбранный идентификатор повторно проверяется через `UniDrReferenceService.selected`; недоступный выбор не заменяет предыдущее значение. Это также применяется к постоянным значениям отборов и начальным значениям параметров.
