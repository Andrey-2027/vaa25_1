# Компактный редактор UniDR — 10.10.2026

Поля представлены таблицей: выбор вывода и название поля, заголовок без повторяющейся подписи, агрегация, порядок и кнопка свойств. Режим отчёта и общий итог расположены рядом. Таблица имеет закреплённую шапку и собственную прокрутку; при узкой области доступна горизонтальная прокрутка.

Из UDR использован принцип палитры выбранного поля. Кнопка «⋯» открывает отдельную область со свойствами: идентификатор источника и заголовок показателя, если поле поддерживает агрегации. Палитра автоматически прокручивается в видимую область. Перестановка строк сохраняет введённые значения. Открытие и закрытие свойств не меняет настройку отчёта.

Модель настройки и сборщик отчёта не расширены: формат, ширина и выравнивание из палитры UDR пока не перенесены. Старый редактор UDR не изменён.
