# R2 №6: создание новых UDR закрыто (2026-10-21)

- Дата: 2026-10-21.
- Основание: R2 №6 в [реестре сценариев](../r2-udr-scenario-inventory.md) —
  «после появления замен закрыть создание новых UDR, временно сохранив
  чтение/экспорт существующих».
- Замены существуют: UniDR покрывает табличный сценарий (S1), query-редактор
  с readonly JPQL и предпросмотром — авторский запрос (S2/S3), JRXML — макеты
  вне приложения. Решения R2-D1/D6 приняты ([ADR-0028](../decisions/ADR-0028-author-query-as-document.md)).

## 1. Что стало верно

**Решение записано в матрицу возможностей.** У `Capabilities` появился флаг
`createNew`: UDR — `false`, JR — `true`, UniDR — `true`. Диалог «Новый отчёт»
строится по этому решению, а не по списку кнопок: UDR-конструктора там больше
нет, основным действием стал UniDR, JR остаётся вторым входом.

**Точка записи защищена, а не только кнопка.** `ReportEditorView.saveTemplate()`
отказывает до сервиса, если у шаблона нет id:

```text
Создание новых UDR закрыто (R2): используйте UniDR или JR.
Открывать, запускать и экспортировать существующие шаблоны можно.
```

Так старый URL `/report-editor` без `id` больше не создаёт шаблон: экран
открывается, но сохранение отклоняется. Тулбар редактора больше не предлагает
«Новый шаблон».

**Существующие сценарии сохранены.** Открытие по id, правка и сохранение,
запуск, копия, экспорт JSON, импорт JSON и удаление — без изменений. Копия и
импорт остаются явными путями миграции: они создают запись из уже
существующего содержимого, а не новый пустой отчёт.

## 2. Последствия для старых URL и ссылок

- `/report-editor` без `id` и `targetEntityClass` — экран пустого черновика;
  сохранение отклоняется с сообщением выше. Ссылка не редиректится: молчаливая
  подмена адреса скрыла бы, что создание закрыто.
- `/report-catalog`, открытие и запуск существующих UDR не менялись.
- Сохранённые UDR-шаблоны не удаляются и не переводятся автоматически: их
  судьба — прод-инвентарь и R3/S8.

## 3. Проверки

```text
mvn -o -B test -Dtest=ReportEngineCapabilitiesTest,
    ReportCatalogViewTest,ReportEditorViewTest,
    ReportEditorViewDirtyTest                         60 тестов, 0 failures / 0 errors
```

- `ReportEngineCapabilitiesTest.onlyLegacyUdrStopsAcceptingNewReports` —
  единственный движок без создания новых отчётов это UDR.
- `ReportEditorViewDirtyTest.creatingNewUdrIsRefusedWhileExistingTemplateStillSaves` —
  отказ происходит до `saveTemplate` сервиса, а существующий шаблон сохраняется.
- Остальные 19 тестов dirty/save переведены на существующий шаблон, чтобы
  продолжать проверять именно ветки сохранения, а не guard.

## 4. Что осталось в R2

- Прод-инвентарь шаблонов и решение по каждому (пересобрать в UniDR / JRXML /
  архив) — вход владельца, как DB1 для UReport.
- S8: судьба старого JSON-формата UDR и конвертера для подтверждённого
  подмножества.
- Перенос данных и таблица соответствия ID (R2 №7).
- `ReportExecutionService`, `ReportTemplate` и редактор удаляются в R3/S4;
  создание новых UDR — первый шаг, а не завершение.
