# AF3.5: визуальная проверка 06.11.2026

Проверены состав и ширины табличных частей, запись вида, повторное открытие,
полный перезапуск приложения и сброс. Блокирующих дефектов AF3.5 не обнаружено;
производственный код по результатам проверки не менялся.

## Стенд и границы

- Настоящее приложение `org.ip.Application`, JDK 21, `accounting-pilot`,
  [localhost:18080](http://localhost:18080).
- База `accounting_object_pilot_af34_20261106`, отдельная копия, подготовленная
  для проверки AF3.4; `ddl-auto=validate`. Исходная база не менялась.
- Пользователь `accounting-pilot`, существующие проверочные документы
  `ПРОБА-У-001` и `ПРОБА-К-001`. Документы открывались без записи изменений.
  Создан только личный вид «AF3.5 — табличная часть» в копии базы.
- Обычное окно 1280×720, дополнительная проверка AUTO при 760×900.
- Для новых объявлений использована временная Spring-фикстура в `target/classes`,
  профиль `af35-visual`. Её исходник сохранён в
  [Af35VisualColumns.java](../../../outputs/verification/af35-visual-fixture/src/org/ip/config/Af35VisualColumns.java).
  Прикладные исходники и модели не мигрировались.
- AUTO: `nomenclature` — `24em`, flexGrow=1; `accountingType` — `16em`, flexGrow=0.
  EXPLICIT: те же свойства, порядок `accountingType,nomenclature`.
  Между режимами приложение полностью перезапускалось.
- После проверки класс фикстуры удалён из `target/classes`, обычный профиль
  снова запущен. Проверочный вид сохранён, отметка «По умолчанию» снята.

## Наблюдения

| Проверка | Результат |
| --- | --- |
| Установка без объявления | Две колонки: Номенклатура, Тип учёта; строка PILOT-01 / ФИФО отображается |
| AUTO | Состав и порядок сохранены; Номенклатура имеет базу 24em и растёт до 479,2 px, Тип учёта фиксирован на 224 px (16em) |
| Узкое окно, AUTO | Тип учёта остаётся 224 px; таблица допускает внутреннюю горизонтальную прокрутку |
| Изменение ширины мышью | Номенклатура уменьшена до CSS 357px, фактически 356,99 px, flexGrow=0 |
| Создание вида с другим составом | В редакторе убран Тип учёта; запись применяет одну колонку и сохраняет 357px / flexGrow=0 |
| Перезагрузка страницы и открытие документа | Вид по умолчанию восстановил одну колонку и ту же ширину |
| Стандартный вид при AUTO | Вернулись обе колонки, порядок и свойства AUTO: 24em / 1 и 16em / 0 |
| Полный перезапуск с EXPLICIT | Сохранённый вид всё ещё имеет приоритет: одна Номенклатура, 357px / 0 |
| Стандартный вид при EXPLICIT | Вернулся явный порядок Тип учёта → Номенклатура, ширины 224 и 479,2 px в обычном окне |
| Корректировка без нового объявления | Три колонки: Номенклатура, Текущий тип учёта, Новый тип учёта; PILOT-01 / ФИФО / ЛИФО отображаются |

«Стандартный вид» применяет исходный состав к текущей таблице. Отметка
«По умолчанию» управляется отдельно: сама команда её не снимает.
После проверки отметка снята явно; запись личного вида осталась доступной.

Измерения получены из видимого DOM грида, включая реальные размеры заголовков:
[measurements.json](../../../outputs/verification/af35-20261106/visual/measurements.json).
Логи запусков: `outputs/verification/af35-visual-{application,auto,explicit,final}.log`.
Первый запуск в ограниченной среде получил `Permission denied: getsockopt` при
обращении к PostgreSQL; повторный запуск с доступом к localhost прошёл.
