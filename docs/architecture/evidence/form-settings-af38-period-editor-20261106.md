# AF3.8: общий редактор периода в FilterGrid — 06.11.2026

Выполнена библиотечная часть AF3.8 в соседнем проекте `../FilterGrid`.
Панель отборов форм, её DSL, параметры открытия и миграция регистров остаются
следующей частью этапа; AF3.8 целиком не завершён.

## Реализация

В `filtergrid-core` добавлены `PeriodRange`, `PeriodField` и `PeriodFilter`.
Один редактор используется отдельно в панели и через `addColumnFilter` в шапке.
Есть фабрики для LocalDate и LocalDateTime, открытые границы, текущий месяц,
текущий квартал, сброс, применение и отмена. Значения в раскрытом редакторе —
черновик: обновление грида происходит только при применении.

Адаптер поддерживает JPA Specification, in-memory predicate и нейтральное дерево
FilterNodeProducer: BETWEEN / GE / LE с включёнными границами. Пустой диапазон
не создаёт условия. Сброс чипа очищает фильтр. Компактный режим передаётся полю
из FilterGrid; CSS ограничивает краткий текст шириной колонки, полное значение
доступно в подсказке и accessible name. Старые фильтры сохранены.

Пресеты вычисляются относительно Clock, datetime заканчивается LocalTime.MAX.
DateTimePicker Vaadin редактирует миллисекунды; нетронутая граница сохраняет
исходные наносекунды при открытии и применении. Изменённая вручную граница имеет
точность редактора. Ошибка обратного диапазона выводится внутри popup.

Документация API и пример: `../FilterGrid/docs/period-filter.md`.
Демо: `../FilterGrid/filtergrid-demo/.../PeriodFilterDemoView.java`, маршрут
<http://localhost:18081/period-filter>. Оно работает с тестовыми строками в памяти
и собственной H2-базой демо, без прикладных данных.

## Уточнение: автоматическое время при вводе даты

После замечания владельца составная граница DatePicker + TimePicker автоматически
подставляет начало дня для «С» и конец дня для «По», если время ещё не задано.
Дата выбирается календарём либо вводится текстом. Ручное время сохраняется
при смене даты; очистка даты очищает границу. При коротком вводе `14:30`
Vaadin дополняет секунды и миллисекунды нулями. Модель сохраняет точный конец дня
LocalTime.MAX, хотя поле показывает миллисекунды. Компактность передаётся
обоим внутренним полям.
