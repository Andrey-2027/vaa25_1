# Реестр сущностей R3 — проверка переходов

Новый реестр подключён флагом `app.entity-explorer.registry.enabled`. В конфигурации приложения флаг выключен. Состояние реестра принадлежит UI, компоненты реестра и карточек принадлежат вкладкам Workspace.

| Переход | Проверка |
|---|---|
| Закрыть и открыть реестр | Новый компонент получает те же фильтр, группировку, раскрытия, выбор и состояние обзора. Реестр не регистрирует URL карточки. |
| Повторно открыть карточку из реестра | Кнопка активирует существующий компонент с сохранённым якорем. |
| Войти по явному якорю | На момент активации якорь установлен в состоянии целевой панели. Вход без якоря сбрасывает адресное место. |
| Холодный вход с `continue` | Перед активацией регистрируется входной URL. После активации для вкладки запоминается адрес без служебного параметра. |
| Программный переход в активную карточку | Переданные место и сообщение применяются к той же карточке. Изменение адреса отправляется через `tabAddressChanged`. |
| Две карточки без ключа, адресованная карточка, реестр и редактор | Компоненты сосуществуют в реальном Workspace. Refresh и закрытие карточки сохраняют dirty-состояние редактора. |
| Back/Forward между URL карточки и `/` | Мост передаёт явный адрес в точку входа Explorer и активирует последнюю живую безадресную вкладку на `/`. Во время Back/Forward он не пишет историю. После закрытия безадресной вкладки выбирается следующая по порядку активации. |
| Закрытие активной после Back | Общий тест моста проверяет замену записи истории. Тест закрытия фоновой вкладки проверяет отсутствие записи. |
| Флаг выключен, допуск отсутствует или якорь неизвестен | Новая вкладка не создаётся. |

Целевой прогон на JDK 21 — 109 тестов. Проверки API baseline и поверхности Vaadin запущены отдельно тем же скриптом. История проверялась тестами моста с подменой браузерного History. Компоненты и переключение проверялись на реальном Workspace в JVM. Действия создания и окно общих диагностик относятся к R4.
