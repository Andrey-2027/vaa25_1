# UniDR: колонка группировки и ширина отчёта

## Изменение

- В подробном отчёте служебная колонка «Группа» удалена. Таблица начинается с выбранного поля или номера строки; заголовки групп остаются отдельными строками.
- В сводном отчёте колонка «Группа» появляется только при заданных группировках. Её ширина ограничена 180 пунктами; длинные подписи переносятся. Ранее относительная ширина 190 раздувалась при подгонке таблицы под страницу.
- Подпись итога занимает подходящую текстовую колонку. Если есть только числовые колонки, используется штатная подпись subtotal внутри первой ячейки итога; значения остаются числами. Подпись группового итога хранится в переменной группы, чтобы на переходе не подставлялось название следующей группы.
- Ориентация страницы определяется количеством действительно отображаемых колонок, без повторного подсчёта показателей и скрытых полей.
