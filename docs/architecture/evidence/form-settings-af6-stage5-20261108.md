### Найдено и исправлено

Первый осмотр показал пустую таблицу без пояснения (`empty-before.jpg`).
В ReceivingDocumentListFormConfig только для workshop-incoming добавлено штатное
Grid.setEmptyStateText: «Входящих накладных пока нет. Создайте накладную или измените отборы.»
Платформенные исходники и публичный API не менялись. После этой правки
повторно прошли все 9 runtime-проверок (`runtime-after-visual-fix.log`).
При осмотре сообщение обрезалось низкой областью грида; варианту задана
минимальная высота 12em штатным API компонента. Сборка после настройки высоты
прошла (`compile-layout-fix.log`). На финальной сборке сообщение целиком видно
в обычном и узком окне (`empty-normal.jpg`, `empty-narrow.jpg`).

### Уже проверено

- 760×900: карточка сохранённого цеха и встроенный список помещаются без
  обрезания; отбор по цеху виден, отличается как readonly, имеет пояснение

  и удаления нет. На панели только создание и обновление.
