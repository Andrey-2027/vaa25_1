# UniDR: выбор полей и порядок группировок

Реализован отдельный список доступных полей и таблица только выбранных колонок. Поля добавляются кнопкой, пакетным выбором в диалоге или перетаскиванием. Удаление из таблицы сохраняет заголовок и оформление для повторного добавления.

Группировки показаны отдельным упорядоченным списком. Поддерживаются перетаскивание, стрелки, удаление и ограничение источника на число уровней. «Считать количество записей» вынесено из списка полей в отдельный флажок. В режиме итогов таблица показывает только показатели.

Проверено в браузере на изолированном H2-примере: добавление и перестановка полей, порядок группировок, пакетный выбор, переключение представления, формирование отчёта. На узком экране используется диалог выбора; широкая версия показывает список слева.

Артефакты: `outputs/unidr-u4/field-selection-20261010.jpg`, `field-selection-narrow-20261010.jpg`. Первоначальная проверка: 199 тестов (`field-selection-verified-gate.log`); последующий прогон с новыми возможностями: 210 тестов (`computed-columns-verified-gate.log`).
