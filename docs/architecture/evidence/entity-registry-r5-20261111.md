# Реестр сущностей R5 — браузерная приёмка

Проверка выполнена в браузере на локальном приложении с временной H2 и демонстрационными данными. Для проверки безадресной истории использовались два синтетических служебных типа и тестовый исторический ключ номенклатуры. Исходники и прикладная база из браузера не изменялись.

| Сценарий | Наблюдение |
|---|---|
| Холодный вход после входа в систему | Номенклатура открылась на вкладке «Поля и колонки». Исторический ключ с `view=fields/table-sections` раскрыл раздел «Табличные части». `continue` остался в исходной записи входа и исчез при последующем выборе рабочей вкладки. |
| Якоря и Back/Forward | Переходы между полями, формами и чтением восстановили выбранный раздел. Повторное открытие номенклатуры из реестра вернуло существующую карточку на сохранённое место. Переход из подсистемы открыл карточку на обзоре. |
| Безадресные вкладки и редактор | Две карточки без опубликованного ключа, реестр и черновик существовали в одном UI. Forward на `/` вернул последнюю безадресную карточку, а после её закрытия — оставшуюся карточку. Текст черновика сохранился. |
| Закрытие фоновой и активной вкладок | До исправления Enter на кнопке фоновой вкладки активировал её. После остановки всплытия событий повторная проверка сохранила активную карточку и URL. Закрытие активной карточки после Back вернуло адрес оставшейся вкладки. |
| Закрытие и повторное открытие реестра | Восстановились фильтр `Nomenclature`, выделение строки и обзор номенклатуры. |
| Редакторы и обновление | Ревизия общих диагностик увеличилась с 0 до 1. Подпись нового реквизита и название черновика сохранились. Отмена замены черновика другим видом и отмена закрытия вкладки также сохранили ввод. |
| Создание | Открылись черновики справочника, документа и регистра. Пункт простой сущности показал пояснение при нажатии Enter и оставил реестр активным. |
| Допуск и ошибки | Неизвестный якорь и вход пользователя с ролью VIEWER по известному адресу показали «Адрес не найден». |
| Размеры и клавиатура | При 1024, 736 и 390 px горизонтальной прокрутки страницы и контейнера реестра не было. Enter выбрал строку дерева. На 390 px возврат из обзора перенёс фокус на выбранную строку. |

После приёмки удалены совмещённый экран и `app.entity-explorer.registry.enabled`. Финальная сборка открыла карточку по прямому адресу, реестр и черновик. Back/Forward повторно переключили разделы карточки, текст черновика сохранился.

На чистой компиляции финальной сборки прошли 178 целевых тестов, 8 проверок API baseline и 6 проверок поверхности Vaadin.
