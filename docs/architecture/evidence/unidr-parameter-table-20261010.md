# UniDR: таблица параметров с палитрой — 2026-10-10

Параметры стандартного источника представлены компактной таблицей: подпись, тип, способ задания начального значения. Кнопка с подписью выбирает параметр и открывает его свойства справа. Палитра содержит привязку к полю и условию, тип, подпись, начальное значение и удаление пользовательского параметра вместе с его отборами. Параметры источника удалить нельзя. При создании нового параметра его палитра открывается сразу.

Каждый параметр сохраняет свои экземпляры контролов: переключение строк не теряет значения и не меняет определение отчёта. Значения для запуска остаются отдельными от объявления параметра. Вкладка «Параметры отчёта» занимает всю ширину рабочей области; при ширине до 750 px палитра располагается под таблицей. Для произвольного запроса сохранён существующий редактор UDR `ReportParamEditor`, уже содержащий таблицу и правую палитру.
