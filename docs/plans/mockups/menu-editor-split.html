Пользователь видит пункт, если есть права. Пустые разделы скрываются.
  1. Выбор меню: «Основное меню» или именованное. «Копия» — копия текущего; «⋯» — переименовать, «Кому назначено», удалить. «Сохранить» активна только при несохранённых правках.
  2. Кому назначено именованное меню (конкретные пользователи; роли не участвуют). У «Основного меню» строки нет — оно для всех остальных.
  3. Левая половина — предметные области из кода, только чтение: списки, под ними их команды, группа «Без области».
  4. Галочка — пункт уже есть в этом меню, «×2» — в двух разделах. Без галочки — в меню нет (отдельная панель «Нет в меню» не нужна).
  5. Перетаскивание слева направо добавляет пункт; линия справа показывает место. Кнопка «→» — то же с клавиатуры. «→» у области — раздел со всеми её списками, связанный с областью.
  6. «новое» — сущность появилась в коде и ещё не размещена ни в одном меню.
  7. Правая половина — выбранное меню. «+ Раздел» — раздел верхнего уровня.
  8. Скрепка — раздел связан с областью: её новые сущности автоматически попадают сюда (в каждом меню — своя связь).
  9. Команда (молния) видна там, где её положили, если у пользователя есть право.
  10. Переименование — двойным щелчком в строке.
  11. «⋯» у раздела: значок, отвязать от области, удалить. «⋯» у пункта: важность, вернуть исходный заголовок, убрать.
  12. Важность пункта: «Важное» — жирным, «Обычное» — как есть, «См. также» — приглушено (пример — «Филиалы»). На странице раздела: важное первым, «См. также» — отдельной группой в конце.
