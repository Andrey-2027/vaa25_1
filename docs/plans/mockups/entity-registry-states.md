Группировка по умолчанию в источнике — «По видам»; «По подсистемам» — состояние того же экрана. Сброс виден при активных фильтрах, пустой результат — при нуле совпадений. Начальный широкий снимок `entity-registry-tree-overview-20261110.png` сохранён как предыдущий исторический снимок, а текущая передача в реализацию использует этот набор.

Это визуальная основа, а не обещание действующих возможностей генератора. Демонстрационные сущности/счётчики не являются измерением текущего приложения; режимы создания и редактора иллюстрируют переходы. Поддержку `PLAIN`, дополнительный набор административных фильтров, окончательные подписи вкладок и упрощение повторов уточняет [основной план](../entity-registry-ux-plan.md). Эти уточнения перечислены явно и не должны выводиться из старого снимка по догадке.

В рамках сохранения набора проверены отображение всех шести состояний, сброс и пустой результат, переключение группировки и узкий переход к обзору. Ошибок JavaScript не получено. Необязательные иконки внешнего runtime могут отсутствовать при сетевых ограничениях; существенные действия имеют текстовые подписи.
