Команды перечня. «Создать» открывает пустой редактор. «Изменить» — редактор выбранного списка. «Копировать» создаёт новый список с другим ключом, в том числе из списка, объявленного в коде. «Выключить / Включить» работает без открытия редактора. «Открыть» показывает настоящую ссылку query-list/<ключ> в новой вкладке — так, как увидит сотрудник, но с правами администратора. «Удалить» — с подтверждением. «Проверить все» заново проверяет все определения (при запуске приложения это уже сделано).
  2. Списки, объявленные в коде, показаны рядом со списками из БД: видно, какие ключи заняты и что можно положить в меню. Они только для чтения, без автора и версии: доступны «Изменить» (только просмотр), «Копировать» и «Открыть».

  4. Выключенный список хранится, но по ссылке не открывается; в меню (FQ-8) его пункт станет устаревшим. Удалить можно и включённый — после подтверждения.

Вкладка «Запрос» готово: редактор и конструктор с /queries

select d.id as document, w.id as warehouse, d.date as date,
       sum(i.amount) as amount
from ReceivingDocumentItem i
  join i.document d
  join d.warehouse w
where d.date between :periodFrom and :periodTo
  and (:warehouse is null or w.id = :warehouse)
  and d.organization.id = :organization
  and d.status = :status
group by d.id, w.id, d.date
Запрос проверен: 4 колонки, ключ строки — Накладная.8
  1. Под редактором — одна строка результата проверки, без отдельной таблицы возможностей колонок: что можно отбирать и сортировать, видно на вкладке «Вид». При ошибке здесь же причина: «Колонка результата должна иметь алиас», «Нет права чтения: Склад» и т. п. Параметры запроса объявляются в редакторе, как на /queries; как сотрудник получает их значения, задаёт вкладка «Параметры».

Источник значения: «Вводит пользователь» — поле на панели над списком, с необязательным значением по умолчанию. «Постоянное значение» — обязательное условие администратора: сотрудник его не видит и не меняет. «Вычисляется» — при каждом запуске, только для чисел, строк и дат: ссылку на организацию пользователя запрос сравнивает по id (d.organization.id = :organization). Вкладка «Команды» — FQ-7
Основная сущность и колонка объекта команды (выбор из проверенных колонок идентичности), галочки «Создать», «Открыть», «Изменить», «Удалить». Поля уже есть в определении и проверяются; вкладка появится вместе с выполнением команд, чтобы результат настройки был сразу виден.
«Где используется» — FQ-8
Пункты основного и именованных меню со ссылкой на список. Список попадает в меню через редактор меню (СМ-3), в разделе «Все функции».
Входы с других экранов — отложено
«Создать список по запросу» на /queries и из табличного отчёта UTR. Пока администратор пишет или вставляет запрос прямо в редакторе.
