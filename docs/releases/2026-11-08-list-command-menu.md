# Меню формы списка — 08.11.2026

ListForm и SelectionForm используют общую панель с полным меню «Ещё». При сужении кнопки
сворачиваются без второй строки; активная скрываемая кнопка передаёт фокус на «Ещё».
Кнопки имеют единые размеры/оформление, подписи не смешиваются с причинами отказа:
объяснение доступно через tooltip и accessible description. Горизонтальная прокрутка
меню и вложенного «Сервиса» устранена.

## Что изменилось для пользователя

- Просмотр и Удалить находятся в «Ещё»; Создать, Копировать, Изменить, Виды, Печать,
  Обновить и прикладные действия появляются на панели по умолчаниям/настройке формы.
- Настройки грида сгруппированы в «Настройки», ссылка/разработка — в «Сервис».
  Пустые группы не отображаются; поиск показывает актуальное checked-состояние.
- Режим компактности ListForm удалён; старое значение `compact=true` игнорируется.
  Остальные сохранённые настройки и виды не сбрасываются.
- Прототип `/command-bar-demo` и его отдельная реализация удалены из production.
  Полезные сценарии перенесены в проверки общего рендерера и реальных форм.

## Что проверить в прикладном коде при обновлении

Сохранены сигнатуры конструкторов ListForm/SelectionForm, `getToolbar(): HorizontalLayout`,
CRUD-геттеров кнопок, `installMoreMenu()`, `addAction()`, `FilterGridMoreMenu.create()`
и ActionDefinition. Это ограниченная поведенческая совместимость:

| Старый приём | Новое поведение / перенос |
| --- | --- |
| `getToolbar().add(component)` | Добавляет во вторую область под основной строкой. Собственный компонент не получает пункт «Ещё». |
| Индексы, `getChildren()`, обход toolbar | Видят только дополнительную область. Не ищите там штатные кнопки. |
| `getToolbar().removeAll()` | Очищает дополнительную область, сохраняет штатные команды. Для пустого состава — `commands()`. |
| `getToolbar().remove(getDeleteButton())` | Исключает штатную команду и её пункт меню; чужая кнопка другой формы отклоняется. |
| Прямые `setVisible/setEnabled/setText/setIcon` штатной Button | Не зеркалятся автоматически в меню и могут быть перезаписаны моделью. Используйте configureCommands/конфигурацию формы. |
| Программный `getDeleteButton().click()` | Сохранён, с повторной проверкой текущего решения и включения команды. Исключённая через эту форму команда не исполняется. |

Собственные компоненты дополнительной области сохраняют обычные Vaadin-сеттеры.
Меню не меняет серверные полномочия: исключение команды — настройка UI конкретной формы.

Новые входы: `ListFormVariants.commands(...)`, `ListForm.configureCommands(...)`,
`ListCommandLayout`, `ListUiCommand`. Состав INHERIT/AUTO/EXPLICIT отделён от панели;
ссылки REQUIRED/OPTIONAL/LOCAL явно различают ошибку ключа, необязательный модуль
и локальную регистрацию до beforeClientResponse.

[Руководство](../forms/list-command-menu.md) содержит компилируемые примеры, включая печать
без обязательной зависимости на модуль отчётов и передачу существующего ActionHandler.
После установки обновлённого platform-vaadin перезапустите приложение.
