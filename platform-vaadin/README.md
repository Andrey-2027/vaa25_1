# platform-vaadin

Vaadin-компоненты платформы. Потребитель предоставляет совместимый Vaadin 25; модуль не зависит от приложения.

## Entity Explorer: переиспользуемое представление

Пакет `org.ipro.vaadin.explorer.ui` принимает готовые immutable `ExplorerSnapshot` / `EntitySummary`.
Компоненты не строят метаданные, не читают БД или Java-файлы и не создают рабочие вкладки.
Оформление поставляется через `@StyleSheet` вместе с JAR; прикладной CSS-класс для читаемости не требуется.
Используются цвета темы с резервными значениями, компактные размеры контролов и ширина самой панели.

```java
var state = new EntityExplorerRegistryState(); // хранит владелец UI, отдельно от компонента
var registry = new EntityExplorerRegistryPanel(snapshot, state, registryActions);
// Новая ревизия фактов, с сохранением фильтров и допустимого выбора:
registry.setSnapshot(refreshedSnapshot);
// Закрытую панель можно пересоздать с тем же state.
```

`EntityExplorerRegistryActions` содержит доступность и callbacks просмотра, изменения, создания по
`EntityKind` и общей диагностики. Версии рецептов, feature flags и роли остаются в приложении.
Объяснение недоступности показывается текстом; callbacks команд повторно проверяют доступность.
`none()` даёт явно недоступные действия и объяснение для неподдержанного создания простой сущности.

Основные фильтры всегда видны. Дополнительные содержат по одному условию `onlyErrors`,
`showServiceTypes`, `exposure`. Поиск сравнивает подпись и simpleName, не реквизиты.
`EntityExplorerRegistryModel` — чистая проекция root-записей; owned-строки не становятся корнями,
а отсутствующий descriptor не считается служебной экспозицией. `UNKNOWN_EXPOSURE` и `NO_SUBSYSTEM`
позволяют явно найти неизвестную экспозицию и отсутствие подсистемы.
Сброс не меняет группировку и сохранённые раскрытия со стабильными ключами.

Дерево поддерживает стрелки, Home/End и Enter/Space. У дерева и обзора независимая прокрутка.
При ширине панели меньше 650 px они показываются последовательно с возвратом и восстановлением фокуса.
Полное имя класса доступно в раскрываемых технических сведениях без обязательного hover.

```java
var cardState = new EntityExplorerCardState(); // отдельный объект для каждой карточки
var card = new EntityExplorerCardPanel(snapshot, type, cardState,
    EntityExplorerCardPanel.Mode.DETAILED, cardActions);
EntityExplorerCardPlace.parse("fields/table-sections").ifPresent(card::applyPlace);
```

Приложение выбирает начальный подробный/компактный режим; платформа не содержит пилотного списка типов.
Явное техническое место открывает подробное представление. Программное `applyPlace` не вызывает
callback пользовательской смены места. `EntityExplorerCardPlace` публикует словарь якорей без внутренних
типов компоновки. Сбой сборки имеет отдельное читаемое представление.

`ExplorerSourcePort` — необязательный порт чтения подтверждённого символа. Разрешённые корни,
допуск и проверку соответствия символу реализует приложение на каждый запрос; путь из браузера
компонент не принимает. `ExplorerFormPreviewPort` — отдельный необязательный порт предпросмотра:
обычный показ фактов не вызывает фабрику формы. Без портов видны доступные текстовые объяснения.
`openStructure` и `registry` в действиях карточки можно оставить `null`, чтобы скрыть внешнюю навигацию.

`EntityExplorerDiagnosticsPanel` показывает только настоящие непривязанные сообщения переданного снимка.
Неизвестная диагностика отделена от подтверждённого нуля ошибок.

Старые прикладные панели сохранены как ветка отката до отдельного этапа R7. Новые платформенные
компоненты не требуют их присутствия; прикладная проводка нового реестра относится к R3/R4.

## Проверки R2

Из корня checkout:

```powershell
./scripts/test-entity-registry-platform.ps1
./scripts/run-entity-registry-platform.ps1 -Action Prepare
./scripts/run-entity-registry-platform.ps1 -Action Start
```

Стенд на `127.0.0.1:8094` использует ограниченную fixture, без приложения и БД.
`-Action Stop` завершает только процесс с совпадающими PID, путём и временем запуска.
Для самостоятельной Maven-проверки модуля:

```powershell
mvn -o -f platform-vaadin/pom.xml -Dtest=EntityExplorerRegistryTest,VaadinModuleCompositionTest test
```
